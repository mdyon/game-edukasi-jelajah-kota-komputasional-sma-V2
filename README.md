# Kota Komputasional SMA Adventure v2

Game edukasi Informatika SMA dengan eksplorasi karakter 2D.

## Fitur utama
- Login nama dan kelas.
- Karakter dapat bergerak bebas dengan WASD/arrow.
- Kontrol layar untuk HP.
- Collision/rintangan sehingga pemain mengikuti jalur.
- 9 checkpoint/misi berurutan.
- Gedung misi dan rute terbuka bertahap.
- Materi IPO, CPU, Memori, Von Neumann, Sistem Operasi, Input/Output.
- Skor, nyawa, evaluasi tiap misi.
- Laporan akhir berisi nilai, skor, misi tuntas, sisa nyawa dan grafik.
- Tombol cetak/simpan sebagai PDF.
- Progres disimpan di browser.

## GitHub Pages
1. Buat repository PUBLIC, contoh `kota-komputasional-sma`.
2. Upload semua file/folder ini ke ROOT repository:
   - index.html
   - style.css
   - game.js
3. Settings → Pages.
4. Build and deployment → Source: Deploy from a branch.
5. Branch: `main`, folder `/ (root)`.
6. Save.
7. Tunggu deployment.
8. URL: `https://USERNAME.github.io/kota-komputasional-sma/`

Jangan mengubah nama `index.html`, `style.css`, atau `game.js`.
